# 写在前面：给 LangChain 初学者

## 这份文档适合谁？

- 你会一点 Python（能写函数、懂 import、会用 pip）
- 你对 ChatGPT / DeepSeek 这些 AI 工具有基本概念
- 你想用代码来调用大模型、做点有用的东西
- 你看到"Agent""RAG""LCEL"这些词一头雾水

**这份文档的目标**：带你从零写出第一个 LangChain 程序，到能搭建一个带记忆的、会用工具的 AI 应用。

## 学习前你需要知道的几个概念

> 如果你已经知道这些，直接跳到 01 开始学。

### 1. 什么是 LLM / 大语言模型？

就是你平时用的 ChatGPT、DeepSeek、Claude 背后的"大脑"。你发一条消息给它，它给你回一条。技术上我们叫它"大语言模型"（Large Language Model），简称 LLM。

### 2. 什么是 API Key？

API Key 是一个密钥字符串，用来向模型服务商证明"我有权限调用这个模型"。模型服务不是免费的，每次调用都要花钱。API Key 绑定了你的账户和余额。

**就像银行卡密码**——不要把它写到代码里上传 GitHub！用环境变量存储。

### 3. 什么是 Prompt / 提示词？

就是你发给 LLM 的那段话。比如你在 ChatGPT 输入框里打的字，就是一个 prompt。

### 4. 什么是 Token？

LLM 不是按"字"来理解文本的，而是按 token（词元）。一个 token 大约等于 0.75 个英文单词或 0.5 个中文字。模型的收费和上下文长度都按 token 算。

### 5. 什么是"链" (Chain)？

LangChain 名字里的"Chain"就是"链"。意思是把多个步骤串起来：先组织提示词 → 再调用模型 → 再处理输出。就像流水线上的工序，一个接一个。

### 6. 本项目用什么模型？

本项目使用 **DeepSeek**（国产大模型，便宜好用）。你需要先[注册 DeepSeek 账号](https://platform.deepseek.com/)并获取 API Key。

## 遇到问题怎么办？

- 代码报错：先看最后一行错误信息，90% 的问题都在那写着
- API 调用失败：检查 API Key 是否正确、是否有余额
- 概念不懂：往回翻，前面的章节一定有解释
- 还搞不定：把报错信息丢给 ChatGPT / Claude 问
