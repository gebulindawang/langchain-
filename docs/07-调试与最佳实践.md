# 第七章：调试与最佳实践

## 7.1 代码出问题了怎么看？

### 最简单的方法：开 verbose

```python
llm = ChatDeepSeek(model="deepseek-chat", verbose=True)
# 设置后在终端能看到每一步的输入输出
```

### 打印中间结果

管道太长卡住了？拆开来一步一步调：

```python
# 不要一次性调完整条链，拆开看
messages = prompt.invoke({"topic": "Python"})
print("提示词：", messages)

response = llm.invoke(messages)
print("模型输出：", response)

result = parser.invoke(response)
print("最终结果：", result)
```

## 7.2 七条必记的实践原则

### 1. 永远用 LCEL 管道符

```python
# ✅ 新写法
chain = prompt | llm | parser

# ❌ 老写法（v0.x，现在不推荐）
# chain = LLMChain(llm=llm, prompt=prompt)
```

### 2. 固定依赖版本

AI 框架更新太快了，不锁版本过两个月代码可能就跑不起来：

```toml
# pyproject.toml 里固定版本号
dependencies = [
    "langchain==1.3.4",
    "langchain-deepseek==1.1.0",
]
```

### 3. 简单任务用便宜模型，复杂任务用高级模型

```python
# 日常问答、文本总结 → 用基础模型（又快又便宜）
llm = ChatDeepSeek(model="deepseek-chat")

# 复杂推理、数学、编程 → 用推理模型（慢但准）
llm = ChatDeepSeek(model="deepseek-reasoner")
```

### 4. 给模型加"保险"

```python
# 自动重试 3 次
llm = ChatDeepSeek(model="deepseek-chat", max_retries=3)

# 主模型挂了，自动切备用
primary = ChatDeepSeek(model="deepseek-chat")
backup = ChatDeepSeek(model="deepseek-chat")
robust_llm = primary.with_fallbacks([backup])
```

### 5. 让模型直接输出结构化对象，别自己解析

```python
# ✅ 推荐：定义格式，模型直接按格式输出
from pydantic import BaseModel

class Summary(BaseModel):
    title: str
    points: list[str]

chain = prompt | llm.with_structured_output(Summary)
result = chain.invoke({"topic": "..."})
print(result.title)   # 直接 .字段名 取值

# ❌ 别这样：用正则从文本里硬抠
# title = re.search(r"标题：(.*)", text).group(1)  # 很容易出错
```

### 6. 工具的 docstring 写清楚

模型能不能用好你的工具，80% 取决于你的描述写得好不好：

```python
@tool
def search_customers(query: str) -> list[dict]:
    """在客户数据库中搜索。

    参数 query: 搜索关键词，支持姓名、电话、或公司名。
    返回: 匹配的客户列表，每条含 id, name, phone, company。
    如果没找到，返回空列表 []。
    示例: search_customers("张三") → [{"id": 1, "name": "张三", ...}]
    """
    ...

# 好描述 = 干什么 + 参数啥意思 + 返回啥 + 示例
```

### 7. 生产环境用异步

```python
import asyncio

async def main():
    """同时处理 5 个问题"""
    tasks = [chain.ainvoke({"topic": t}) for t in ["Python", "Java", "Go", "Rust", "TS"]]
    results = await asyncio.gather(*tasks)
    return results

# 运行
results = asyncio.run(main())
```

## 7.3 常见问题速查

| 现象 | 可能的原因 | 怎么修 |
|---|---|---|
| Agent 不调工具 | 工具的 docstring 不清楚 | 把描述写详细，包含参数说明和返回格式 |
| 输出格式不稳定 | 模型自由发挥 | 换成 `with_structured_output()` |
| 回答太慢 | 模型太大，链太长 | 换小模型，看看能不能减少不必要的步骤 |
| API 调用报错 | 网络抽风 / 额度用完 | 加 `max_retries` 和 `with_fallbacks` |
| 模型胡编乱造 | 没有给参考资料 | 用 RAG 提供上下文（第五章） |
| 对话"失忆" | 没加 Memory | 用 `RunnableWithMessageHistory`（第六章） |
