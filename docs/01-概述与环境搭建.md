# 第一章：概述与环境搭建

## 1.1 LangChain 是干什么的？

简单说：**LangChain 让你能用 Python 代码来操控大语言模型（LLM），并把它和其他工具组合起来。**

举个例子——你平时用 ChatGPT，是在网页上打字。而用 LangChain，你可以：

```python
# 用代码调用模型，自动化完成一系列任务
回答 = 模型.invoke("帮我总结一下今天的新闻")
```

更进一步，还能让模型：
- 调用你写的 Python 函数（比如查数据库、调 API）
- 根据你的文档回答问题（RAG）
- 记住之前的对话（Memory）
- 像 ChatGPT 网页版一样逐字输出（Streaming）

### v1.0 变化（了解即可）

如果你是 2025 年后开始学的，你用的就是新版 v1.0，不用管旧版。新版更简洁，核心只包含最重要的 5 个模块：**agents（智能体）、messages（消息）、tools（工具）、chat models（聊天模型）、embeddings（向量嵌入）**。

## 1.3 安装

打开终端，进入本项目目录：

```bash
# 安装 langchain 核心 + DeepSeek 集成
uv add langchain langchain-deepseek
```

没有 `uv`？那就用 pip：

```bash
pip install langchain langchain-deepseek
```

## 1.4 设置 API Key

> API Key 就像是你的银行卡密码，不要把它写死在代码里，用环境变量存。

**Windows PowerShell：**
```powershell
$env:DEEPSEEK_API_KEY="sk-你的key"
```

**Mac / Linux 终端：**
```bash
export DEEPSEEK_API_KEY="sk-你的key"
```

或者写成 `.env` 文件更安全：

```
# 在项目根目录创建 .env 文件，写入：
DEEPSEEK_API_KEY=sk-你的key
```

> `.env` 文件记得加到 `.gitignore` 里，别上传到 GitHub！

## 1.5 第一个程序：跑通整个流程

来写你的第一个 LangChain 程序。打开 `main.py`（或新建一个），输入以下代码：

```python
# 第一步：导入需要的组件
from langchain_deepseek import ChatDeepSeek                      # 模型
from langchain_core.prompts import ChatPromptTemplate            # 提示词模板
from langchain_core.output_parsers import StrOutputParser        # 输出解析器

# 第二步：创建模型实例
# model 参数指定用哪个模型，temperature 控制回答的随机性（0=严谨，1=天马行空）
llm = ChatDeepSeek(model="deepseek-chat", temperature=0.7)

# 第三步：写一个提示词模板
# {topic} 是占位符，调用时会替换成你想问的东西
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个擅长用简单语言解释概念的助手。"),   # 系统提示词：设定角色
    ("human", "请解释：{topic}")                              # 用户输入：你的问题
])

# 第四步：用管道符 | 串联成"链"
# prompt | llm | parser  意思是：先拼提示词 → 再调模型 → 最后解析输出
chain = prompt | llm | StrOutputParser()

# 第五步：运行！
response = chain.invoke({"topic": "机器学习"})
print(response)
```

运行 `python main.py`，你应该能看到 DeepSeek 给你解释什么是机器学习。

### 管道符 `|` 到底是什么意思？

你把它理解成"流水线"就行：

```python
链 = 提示词模板 | 模型 | 输出解析
#     ↓            ↓       ↓
#   组织问题  →  调AI  →  清洗结果
```

每个 `|` 把上一步的输出交给下一步的输入，数据从左往右流。

## 1.6 本章小结

下面是你刚学会的东西：

```
你写了一段 Python 代码
    ↓
把一个问题放进模板（prompt）
    ↓
发给 DeepSeek 模型（llm）
    ↓
拿到回答并解析成纯文本（parser）
    ↓
打印出来
```

- **LCEL（LangChain 表达式语言）** 就是那个 `|` 管道符的用法，贯穿整个框架
- 最基础的链路就是：`prompt | llm | parser`
- 你已经迈出第一步了
