# 第二章：核心组件详解

上一章你跑了第一个程序，这章咱们把每个组件拆开来看清楚。

## 2.1 Prompt Templates（提示词模板）

### 这玩意儿干嘛的？

你不可能每次都手动拼一大堆文字发给模型。提示词模板让你**预先把结构写好，留几个空（占位符），用到的时候再填**。

就像做填空题：

```python
from langchain_core.prompts import ChatPromptTemplate

# 方式一：用消息列表（推荐，结构清晰）
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个{role}。"),     # system = 设定 AI 的角色
    ("human", "{question}")             # human = 用户的问题
])

# 填空：把 role 和 question 换成具体内容
messages = prompt.invoke({
    "role": "Python 专家",
    "question": "装饰器是什么？"
})
# 这时候 messages 就是拼好的、可以直接发给模型的内容

# 方式二：更简单的模板字符串
prompt = ChatPromptTemplate.from_template(
    "请用{language}解释：{topic}"
)
```

### MessagesPlaceholder（消息历史占位符）

这个后面第六章讲 Memory（记忆）时会用到。它的作用是：在提示词里留一个位置，插入之前的聊天记录。

```python
from langchain_core.prompts import MessagesPlaceholder

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个有用的助手。"),
    MessagesPlaceholder(variable_name="history"),   # ← 聊天记录塞这里
    ("human", "{input}")                            # ← 当前问题
])
```

> 初学者先记住有这么个东西就行，第六章会实操。

## 2.2 Chat Models（聊天模型）

### 一句话说明

`ChatDeepSeek`、`ChatOpenAI` 这些类，就是你对模型的"遥控器"。你用它们来发消息、收回复。

### 基础用法

```python
from langchain_deepseek import ChatDeepSeek

# 创建遥控器
llm = ChatDeepSeek(
    model="deepseek-chat",   # 用哪个模型（deepseek-chat 便宜够用）
    temperature=0.7,         # 0 = 每次回答一样，1 = 放飞自我
    max_tokens=1024,         # 最多回复多长（1024 token ≈ 500 个中文字）
)

# 调用方式一：直接 invoke（同步，会等着结果返回）
response = llm.invoke("你好，请介绍一下自己")
print(response.content)  # .content 才是回复的文本内容

# 调用方式二：ainvoke（异步，不阻塞其他代码执行）
response = await llm.ainvoke("你好")

# 调用方式三：batch（一次发多问，内部会并行处理）
responses = llm.batch(["介绍一下 Python", "介绍一下 Java", "介绍一下 Go"])
for r in responses:
    print(r.content)
```

> 关于同步 vs 异步：初学者先用 `invoke` 就行，简单直接。等后面做 Web 服务了再用 `ainvoke`。

### 换模型供应商，代码基本不变

LangChain 最大的好处之一：换模型像换电池一样简单：

```python
# DeepSeek（本项目用的）
from langchain_deepseek import ChatDeepSeek
llm = ChatDeepSeek(model="deepseek-chat")

# 换成 OpenAI
from langchain_openai import ChatOpenAI
llm = ChatOpenAI(model="gpt-4o")

# 换成 Anthropic（Claude）
from langchain_anthropic import ChatAnthropic
llm = ChatAnthropic(model="claude-sonnet-4-6")

# 就改这两行导入和初始化，后面的代码完全不用动
```

## 2.3 Output Parsers（输出解析器）

### 为什么需要这玩意？

模型返回的是一个 `AIMessage` 对象，里面有内容有元数据。大多数时候你只想要**纯文本**。解析器就是帮你提取和格式化的。

### StrOutputParser — 只要纯文本

```python
from langchain_core.output_parsers import StrOutputParser

chain = prompt | llm | StrOutputParser()
result = chain.invoke({"topic": "Python"})
# result 是字符串：'Python 是一种...'
# 没有解析器的话，result 是 AIMessage 对象，得多写 .content 才能拿到文本
```

### with_structured_output — 让模型直接输出结构化数据（强烈推荐）

这是 v1.0 最实用的功能。你定义一个 Python 类，模型直接把回复填成这个类的实例：

```python
from pydantic import BaseModel, Field

# 第一步：定义你想要的输出格式
class Person(BaseModel):
    name: str = Field(description="姓名")
    age: int = Field(description="年龄")
    skills: list[str] = Field(description="技能列表")

# 第二步：把格式"绑定"到模型上
structured_llm = llm.with_structured_output(schema=Person)

# 第三步：调用，直接拿到 Person 对象！
person = structured_llm.invoke("张伟，30岁，会 Python、Java、Go")
print(person.name)    # 张伟
print(person.age)     # 30
print(person.skills)  # ['Python', 'Java', 'Go']
# 完全不用自己写正则去解析文本！
```

> `Field(description="...")` 里的描述很关键——它告诉模型这个字段该填什么。写得越清楚，模型输出越准。

## 2.4 三个组件串起来：完整示例

回顾一下，这就是一个完整的链：

```python
from langchain_deepseek import ChatDeepSeek
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

llm = ChatDeepSeek(model="deepseek-chat")
prompt = ChatPromptTemplate.from_template("用不超过{max_words}个字解释：{topic}")
parser = StrOutputParser()

# 三件套串联
chain = prompt | llm | parser

# 用！
result = chain.invoke({"topic": "递归", "max_words": "50"})
print(result)
```

## 2.5 本章小结

这张图记住了，LangChain 基本就通了：

```
你的问题 → [Prompt Template] → [Chat Model] → [Output Parser] → 纯文本结果
            做填空题          调AI大脑       清洗格式
```

| 组件 | 通俗理解 | 关键类 |
|---|---|---|
| Prompt Template | 填空题模板 | `ChatPromptTemplate` |
| Chat Model | AI 大脑的遥控器 | `ChatDeepSeek` |
| Output Parser | 结果清洗器 | `StrOutputParser`, `with_structured_output()` |
| Chain | 把上面三个串起来 | 用 `\|` 符号 |

下一章深入学 `|` 管道符的更多玩法。
